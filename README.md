# 智能屏幕抓拍管理工具

一款面向 Windows 的桌面屏幕抓拍与图片管理工具。它可以把屏幕截图按主题归档，提供缩略图浏览、批量处理、PDF 合并、快捷键抓拍和图片摘要等功能，适合日常资料整理、会议记录、网页存档和工作留痕。

## 功能亮点

### 屏幕抓拍与主题归档

- 一键抓取当前虚拟桌面屏幕。
- 支持全局空格快捷键抓拍。
- 支持语音触发抓拍（需要可用的语音输入设备）。
- 每个主题自动对应一个图片目录。
- 连续抓拍时自动检测与上一张完全相同的图片，重复文件不会保留。

### 缩略图与图片管理

- 左侧目录树按“主题 / 图片”管理内容。
- 下方缩略图支持横向滚动、预览和快速浏览。
- 缩略图支持普通点击、`Ctrl` 多选、`Shift` 范围选择。
- 选中缩略图后按 `Delete` 或 `Backspace`，只删除当前多选图片。
- 预览区支持复制图片、另存为和删除当前图片。
- 双击缩略图可打开图片摘要窗口。

### 批量尺寸调整

- 支持选择任意图片来源目录。
- 输出目录默认位于来源目录下的 `resized` 文件夹。
- 支持自定义其他输出目录。
- 使用百分比调整尺寸，横拍和竖拍均保持原比例。
- 显示处理进度、当前处理文件和处理结果。
- 输出目录自动生成 `resize.log` 修改日志。

### PDF 合并

- 支持选择任意图片目录作为合并来源。
- 默认使用当前抓拍图片目录。
- 支持自定义 PDF 输出目录。
- 支持编辑 PDF 文件名，自动补全 `.pdf` 扩展名。
- 合并前显示图片数量，按文件修改时间顺序生成 PDF。

### 界面与体验

- 无系统原生标题栏的艺术化窗口设计。
- 标题居中显示：“智能屏幕抓拍管理工具”。
- 实时显示系统时间。
- 支持窗口最小化、最大化、关闭和拖动。
- 支持托盘运行和窗口恢复。

## 快速开始

### 绿色版用户

下载绿色版压缩包并解压，双击以下文件即可运行：

```text
dist/ScreenSnap/ScreenSnap.exe
```

绿色版不需要安装 Python，也不需要安装额外运行环境。

### 源码运行

建议使用 Python 3.10 及以上版本：

```bash
pip install -r requirements.txt
python run.py
```

## 使用说明

1. 在顶部选择或新建一个抓拍主题。
2. 使用快捷键、语音或托盘菜单进行抓拍。
3. 在左侧目录或下方缩略图中选择图片。
4. 使用 `Ctrl` / `Shift` 选择多张图片后，可以批量删除或调整尺寸。
5. 使用“合并为 PDF”将指定目录中的图片导出为 PDF。

## OCR 与图片摘要

图片摘要功能会优先尝试使用 Windows OCR。若系统没有安装对应的中文 OCR 语言包，程序会提示 OCR 组件不可用，但不会影响抓拍、图片管理和 PDF 功能。

如果配置了 DeepSeek API Key，摘要功能可以进一步生成图片内容总结；不配置 Key 时使用本地文本整理。

## 项目结构

```text
ScreenSnapSoft/
├─ app/
│  ├─ main.py             # 程序入口
│  ├─ main_window.py      # 主窗口与交互逻辑
│  ├─ capture.py          # 屏幕抓拍
│  ├─ storage.py          # 主题与图片存储
│  ├─ pdf_export.py       # PDF 导出
│  ├─ ai_summary.py       # OCR 与图片摘要
│  └─ thumbs.py           # 缩略图缓存
├─ models/                # 语音识别模型
├─ picture/               # 默认图片保存目录
├─ dist/                  # 绿色版输出目录
├─ requirements.txt
├─ ScreenSnap.spec
└─ run.py
```

## 本地构建绿色版

```bash
python -m PyInstaller --noconfirm --clean ScreenSnap.spec
```

构建完成后，绿色版目录位于：

```text
dist/ScreenSnap/
```

## 注意事项

- 快捷键抓拍默认使用空格键，如果空格键已被其他程序注册，可能需要退出冲突程序。
- 语音功能需要麦克风权限和可用的语音识别模型。
- OCR 能否使用取决于 Windows OCR 语言包是否安装。
- 图片和 PDF 输出目录可能包含较大的文件，建议定期备份。

## 适用场景
